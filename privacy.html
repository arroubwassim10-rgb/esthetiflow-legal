Privacy Policy – Shorts Pipeline

Last updated: 2026-10-10

Shorts Pipeline is a private, single-owner tool operated by EsthétiFlow (the "owner") to prepare original videos and publish them to the owner's own YouTube channel, EsthétiFlow (@esthetiflow). It is not offered to other users and has no sign-up: only the owner connects a Google account.

Google API Services and Limited Use

Shorts Pipeline's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. The tool also uses YouTube API Services and is subject to the YouTube Terms of Service and the Google Privacy Policy.

Data received from Google APIs is used only to provide the features described below to the owner. It is not sold, not used for advertising, not used to build or train AI models, and not read by humans except the owner.

What the tool accesses, and why

The owner connects once with Google OAuth. The tool requests only these permissions:

  • YouTube Data API (youtube.upload, youtube): to upload the owner's videos to the owner's channel and set their title, description, tags, audience ("not made for kids"), publication time and visibility.
  • YouTube Analytics API (yt-analytics.readonly, read only): to read the statistics of the owner's own channel (views, watch time, subscribers) and write a weekly report for the owner.
  • Gmail API (gmail.send, send only): to send notifications and reports to the owner's own address. The tool cannot read, list or delete any e-mail.
  • Google Drive API (drive.file): to store the owner's videos in a folder the tool creates, before publication. The tool cannot see any other file in Drive.

The tool also reads public information about public videos (titles, view counts, publication dates) through a YouTube Data API key, to study which topics work. It reads no personal data of viewers or other channels' owners.

What is stored

  • An OAuth refresh token, stored as an encrypted secret in the owner's private cloud environment.
  • Video files, scripts and the channel's statistics and reports, in the owner's private storage. No data about any other person is collected.

Service providers

The tool runs in a private cloud execution environment operated by Anthropic (Claude Code), where an AI assistant carries out the owner's tasks, including reading the channel statistics to write the weekly report. Illustrations and narration are generated through the Google Gemini API from the owner's own scripts; no Google account data is sent for that. These providers act for the owner. Nothing else is shared with, sold to or transferred to third parties.

Security

The OAuth token is kept as an encrypted secret and never written in the public code or in videos. Access can be revoked at any time (see below).

Retention and deletion

Channel statistics received from the YouTube APIs are refreshed or deleted within 30 days. Videos and scripts are kept until the owner deletes them. To stop all access, the owner revokes the permission at https://myaccount.google.com/permissions (for YouTube also at https://security.google.com/settings/security/permissions); the stored token is then deleted and the tool can no longer reach any Google data.

Children

The tool is not directed to children and collects no data from them.
