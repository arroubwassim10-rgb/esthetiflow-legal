Privacy Policy – Shorts Pipeline

Last updated: 2026-10-10

Shorts Pipeline is a private tool operated by EsthétiFlow to publish videos that the owner creates to the owner's own YouTube channel, EsthétiFlow (@esthetiflow). It is not offered to other users.

What the tool accesses

Through Google OAuth, with the owner's consent, the tool uses:

  • YouTube Data API: to upload the owner's videos to the owner's channel, set their title, description, tags, audience ("not made for kids"), publication time and visibility.
  • YouTube Analytics API (read only): to read the statistics of the owner's own channel and write a weekly report for the owner.
  • Gmail API (send only): to send notifications and reports to the owner's own address.
  • Google Drive API (files created by the tool only): to store the owner's videos before publication.

What is stored

  • An OAuth token, stored as an encrypted secret in the owner's private cloud environment.
  • Video files, scripts and channel statistics in the owner's private storage. No data of any other person is collected. The tool reads no viewer data other than the aggregated statistics YouTube Analytics provides to every channel owner.

Sharing

No data is sold, shared with or transferred to third parties.

Google and YouTube

This tool uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service (https://www.youtube.com/t/terms). Google's Privacy Policy applies: https://policies.google.com/privacy. Access can be revoked at any time from https://myaccount.google.com/permissions (YouTube's security settings page: https://security.google.com/settings/security/permissions).

Retention and deletion

Data is kept only as long as needed to publish and analyse the channel's videos. Revoking the OAuth access stops all access immediately; stored tokens and files are then deleted.
